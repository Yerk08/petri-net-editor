# Сторонние компоненты и лицензии

Проект распространяется на условиях **GNU General Public License v3.0**.
Полный текст лицензии находится в файле [`LICENSE`](./LICENSE).

## Текущий состав

На момент этой версии в проекте **нет сторонних библиотек, шрифтовых файлов,
иконок или других ресурсов**, для которых требовалось бы прикладывать отдельную
лицензию.

| Компонент | Источник / лицензия |
|---|---|
| HTML, CSS, JavaScript | Оригинальный код проекта, GPL-3.0 |
| SVG-иконки интерфейса | Оригинальные, нарисованы для проекта |
| Шрифты | Системные шрифты ОС (`system-ui`, `Georgia`, `ui-monospace` и т.п.). Файлы шрифтов в репозиторий не включены и не распространяются |
| Эмодзи | Отображаются средствами операционной системы |
| `client/icon.png` | Существующий ресурс проекта, добавлен до этих изменений |
| `examples/order-processing.json` | Оригинальный тестовый пример |

Внешних CDN, npm-зависимостей и сетевых шрифтов нет. Приложение работает офлайн
после первой загрузки.

## Если будете добавлять сторонние ресурсы

- **Шрифты** — обычно лицензия SIL Open Font License 1.1; положите рядом
  `OFL.txt` и укажите автора шрифта.
- **JavaScript-библиотеки** — для MIT / Apache-2.0 / BSD приложите текст
  соответствующей лицензии и copyright-уведомление.
- **Иконки и изображения** — проверьте лицензию автора и условия атрибуции.
- **GPL-совместимость** — не добавляйте код с лицензией, несовместимой с GPL-3.0.

## Примечание

В `LICENSE` находится полный текст GPL-3.0. При публикации проекта рекомендуется
добавить в начало `LICENSE` или в отдельный `NOTICE` строку вида
`Copyright (C) 2026 <имя автора>` — это помогает однозначно зафиксировать
правообладателя. Если `client/icon.png` взят из стороннего источника,
его происхождение и лицензию стоит проверить отдельно.
