# Petri Net Editor

Легкий и удобный редактор сетей Петри с поддержкой симуляции, сокрытия фрагментов сети и продвинутого анализа.

### [**Открыть в браузере:** https://yerk08.github.io/petri-net-editor/](https://yerk08.github.io/petri-net-editor/)

## 🌟 Особенности

* 🖱️ **Интуитивное управление:** Кнопки и горячие клавиши для режимов курсора, симуляции и сброса.
* 📝 **Гибкое моделирование:** Позиции, переходы, дуги и возможность их скрытия для "горячей" замены структуры во время симуляции.
* ▶️ **Интерактивный лог:** В режиме симуляции позволено менять разметку во время работы, а также ведется история шагов для Вашего анализа.
* 💾 **Экспорт:** Сохранение графов в форматах JSON, их экспорт в SVG и PDF (через Print).
* 🎨 **PWA:** Поддержка Offline-режима, установки как мобильного приложения и темной/светлой темы.
* 🔍 **Распределенный анализ (TBD):** В будущем планируется запуск анализа сетей с помощью распределенного кластера, участником которого сможет стать любой желающий.

## 🛠 Contributing (Разработка)

### 💻📱 Редактор сетей Петри

Для локального запуска проекта достаточно открыть файл `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

⚠️ **Важно для разработчиков:** При редактировании кода на `localhost` обязательно закомментируйте или временно удалите в самом низу файла `index.html` скрипт, подключающий `sw.js` (Service Worker). В противном случае браузер закеширует старую версию приложения, и вы не увидите изменения в коде до полной очистки кеша.

### 🗄️ Сервер распределенного анализа (TBD)

Пока идет процесс разработки есть минимальный тестовый сервер на Flask для симуляции выполнения задач анализа.

Для запуска сервера выполните следующие шаги:

1. **Установить зависимости**  
   Убедитесь, что в системе установлены Flask и библиотека для поддержки кросс-доменных запросов (CORS):
   ```bash
   pip install Flask flask-cors
   ```

2. **Запустить скрипт**  
   Запустите mock-сервер из терминала:
   ```bash
   python mock.py
   ```

3. **Проверить готовность**  
   Сервер запустится локально в режиме отладки. В консоли отобразится:
   ```text
   Mock-сервер запущен на http://127.0.0.1:5000
   ```

4. **Базовый URL для интеграции**  
   Все запросы от фронтенд-приложения должны быть направлены на:  
   `http://127.0.0.1:5000/mock`
